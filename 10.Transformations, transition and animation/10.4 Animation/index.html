Анимация

Основы анимации

  • Создание ключевых кадров со списком анимированных свойств
  • Применение анимации к элементу анимации

Свойства переходы

Нюансы

  • Работает во всех основных браузерах, но в IE только с 10 версии. Поэтому необходимы вендорные префиксы. То есть нужно написать 2 анимации: с префиксами и без.
  • Основным преимуществом является необязательный инициатор
  • Лучше добавлять кавычки в имени анимации, чтобы избежать конфликтов с ключевыми словами.

Порядок работы

  1. Настройка ключевых кадров: 
    @keyframes имяАнимации {
  from{
    /*свойства css начального кадра*/      
  }

	50%{
		/*свойства css*/
	}

	70%, 80%{
		/*свойства css c 70% по 80% (без кадра ниже)*/
	}

	75%,85%{
		/*свойства css. С кадром выше произойдет попеременное изменение на 75%, 80% и 85%*/
	}

  to{
    /*свойства css конечного кадра*/   
  }
}
    Кадров не должно быть меньше 2х, логично же. Ключевое слово from можно заменить на 0%, а to на 100%.
  2. Применяем анимацию к конкретному элементу или псевдоклассу 
    .example {
	-webkit-animation-name: 'имяАнимации';
	-webkit-animation-duration: 1s;
	animation-name: 'имяАнимации';
	animation-duration: 1s; /*продолжительность анимации*/
	animation-name: 'fadeIn', 'blink'; /*пример добавления нескольких анимаций*/
	animation-duration: 1s, 2s; /*продолжительность анимациq*/
}
  3. Можно добавить тайминг анимации animation-timing-function: ease; Может принимать в себя ключевые слова (linear, ease(по умолчанию), ease-in, ease-out и ease-in-out) или кривую Безье. Можно применять как к элементу, так и к отдельным кадрам. Не забудь про префиксы!
  4. Можно добавить отсрочку старта анимации animation-delay:2s; Не забудь про префиксы!
  5. Настраиваем повторение анимации. Свойство animation-iteration-count: /*значение*/; принимает в себя число, либо ключевое слово infinite для бесконечного повторения.
  6. Чтобы анимация при нечетных воспроизведениях проигрывалась вперед, а при четных назад используется свойство (к анимированному элементу) со значением animation-direction: alternative;. Также нужно добавить animation-iteration-count: 2;
  7. Чтобы сохранить элементу вид по окончанию анимации (например при выходе курсора), нужно добавить свойство (к анимированному элементу) animation-fill-mode: forwards;
  8. Можно сократить запись: 
    					
.example {
	animation-name: fadeIn;
	animation-duration: 2s;
	animation-timing-function: ease-in-out;
	animation-delay: 5s;
	animation-iteration-count: 2;
	animation-direction: alternate;
	animation-fill-mode: forwards;
}
    на 
    					
.example {
	animation: fadeIn 2s ease-in-out 5s 2 alternate forwards;
}
    Важно соблюдать порядок. И запятые если анимаций несколько. Обязательны только имя анимации и длительность. И не забывать про вендорные префиксы.
  9. Можно еще управлять паузой и воспроизведением анимации. Например при наведении курсора анимация должна приостановиться. Для этого используется свойство animation-play-state:/*running для запуска и paused для остановки*/ Опять же не забывать про префиксы.
