Маштабирование

Для маштабирования применяется свойство transform: scale (/*коэффицент маштабирования*/));

Нюансы

  • КМ: от 0 до 1- уменьшение, от 1 - увеличение, 0 - невидимый на странице, два значения соответствуют трансформации по ширине и высоте, если значения отрицательные то объект перевернется;
  • Используется совместно с :hover;
  • Не забывай использовать префиксы для отдельных браузеров
  • Можно также использовать свойства scaleX() и scaleY() для изменения по определенной оси.

Примеры

scale(0)
scale(1)
scale(2)
scale(.5)
scale(.1)
scale(1.5,1)
